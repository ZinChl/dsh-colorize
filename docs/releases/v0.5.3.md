# v0.5.3 — 首个公开发布

**界面调色师**：按快捷键进拾色模式，点界面上任意元素就地改色。这是第一个公开版本，
把 0.1～0.5.3 的全部工作一次放出。

## 装

```bash
# 从 GitHub（推荐）
dsh plugin --profile web add github:ZinChl/dsh-colorize
dsh web    # 重启进程让 profile 变更生效（刷新页面不够）

# 或者用这个 release 的 tarball
dsh plugin --profile web add \
  https://github.com/ZinChl/dsh-colorize/releases/download/v0.5.3/dsh-colorize-0.5.3.tgz
```

tarball 旁边的 `SHA256SUMS` 可以先校验。

## 能做什么

| | |
| --- | --- |
| **拾色** | 快捷键 `Ctrl+Shift+K`（可改）/ 设置 → 常规 →「自定义色彩」/ 控制台 `__dshColorize.open()`。悬停高亮，单击选中 |
| **改色** | 面板列出该元素**实际生效**的颜色属性：背景 / 文字 / 边框（四边同色合并）/ SVG 填充与描边 |
| **两种取色器** | **调色盘**（系统取色器 + 吸管 + 15 预设色）/ **混合器**（R/G/B/A 滑杆 + HEX），共用「应用 / 取消」 |
| **行内直改** | 每行都能直接改 `HEX` 与不透明度（0–100），不必进编辑器 |
| **批量** | 应用范围：仅此元素 / 同类 N 个 / 含后代 N 个，切换时搬移已有规则 |
| **语义色** | 颜色命中 `--dsw-alias-*` 时改 **token 层**，整个界面跟着变，比元素级规则稳 |
| **背景排查** | 自动给出「含背景图」「::before/::after」「祖先」「覆盖式子元素」四种候选行 |
| **持久化** | 规则存 `localStorage`，插件设置页可逐条改/删，支持导出导入 |

改色只写 CSS 规则和 `theme.overrideTokens`：**不注入脚本、不改圆角字号间距、不碰 profile**。
不进拾色模式时没有定时器、没有 DOM 观察者 —— 常驻只有一条 `<style>`、一个快捷键命令、一个零尺寸挂载点。

## 这一版修了什么

* **滑块与透明度**：编辑器开着时，行内改的不透明度会被下一次拖动写回旧草稿（用户看到的就是
  「用了滑杆，透明度没了」）。现在编辑器会跟进外部改动，自己写的回声忽略。
* **透明度看得见**：行内 HEX 半透明时显示 8 位（`#adb2b866`）；三处色块改用 `toCss` 上色；
  不透明度输入框 46→56px（`100` 曾被箭头压成 `10C`）。
* **显式 alpha 生效**：`#rrggbbaa` / `#rgba` / `rgba(...)`（含 `/ a` 与百分比写法）以输入为准；
  6 位 hex 保留行内当前不透明度。
* **百分比 alpha 修复**：`rgba(0,0,0,40%)` 曾经被 clamp 成 1，透明度静默消失。
* **语义色行补上 HEX / 不透明度**：以前那一行只有色块 + 明/暗勾选，完全看不出 alpha。
  另外：行内改 hex 不再重置不透明度、浮层面板不再被设置弹窗盖住、退出后高亮框不再残留、
  只能改一句文字 → 支持同类/含后代批量。

## 已知限制

* 只声明 `web` 平台；桌面壳没有验证过。
* 只能改颜色（含不透明度），不改圆角 / 字号 / 间距。
* 规则是**选择器 + `!important`**，官方改版换了 class 名就可能失配 —— 重新拾取即可；
  想更稳就用语义色（token）那一行。
* `web:linux` 没有默认快捷键（原因见 README 的说明），请用设置页按钮或自行改键。
