# v0.5.6 — 面板可拖动；目标放宽时保留你选中的元素

## 1. 拖拽面板

标题栏左边多了 `⠿` 抓手，整条标题栏（按钮除外）都能按住拖动：

* pointer 事件 + `setPointerCapture`，指针移出面板也不中断；位置被夹在视口内，拖不丢。
* 拖过之后位置固定 —— 自动摆放仍会在内容变高时夹边，但不会把手动位置拉回元素旁边。
* 换目标（重新拾取 / 改 `目标`）后恢复自动摆放；标题栏上的按钮不受影响。

实测：拖 (+120, −90) → 面板 `[10,160] → [130,70]`；再打开调色盘，位置保持且面板仍在视口内；
往外拖到 (5000,5000) → 夹到 `[669,430,993,893]`（视口 1001×901）。

## 2. 目标：不再跳到第一个匹配项

在 `目标` 里放宽选择器（例如从 `[data-row-key="session:…"]` 改成 `.sessionRow` 以影响全部行）时，
以前会直接取第一个匹配项重新检查 —— 面板和你的选择一起「跳走」，看着像匹配了当前元素而不是你选中的那个。

现在**只要你点选的元素仍然匹配新选择器，就继续用它**（行、高亮框、取色都还是它）；只有它不匹配时才退回第一个。
规则仍然写你输入的选择器。

实测：选中第 3 个按钮 → 目标改 `button`（43 个匹配）→ 高亮框仍在第 3 个按钮 `[10,114,37,37]`，
不是第一个 `[10,18,36,36]`；规则仍是 `button { color: … }`。

安装同 README；已装过的刷新页面（F5）即可，面板标题应显示 `v0.5.6`。
