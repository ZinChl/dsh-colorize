# v0.5.5 — 目标可手动改，面板不再卡出屏幕

## 1. 目标（选择器）可编辑并重新匹配

`目标` 从只读文本变成输入框：改完选择器按**回车**或**离开输入框**即重新匹配 —— 面板按第一个匹配元素
重新检查颜色属性，规则也写在你输入的选择器上。匹配数量实时显示；语法错误 / 无匹配 / 为空会标红并说明
原因，**不会丢掉当前选择**。`Esc` 只还原这次输入，不关面板。

| 输入 | 结果 |
| --- | --- |
| `.wSkVaW_root` | `匹配 1 个`；改背景后规则 `.wSkVaW_root { background-color: #123456 !important; }` |
| `button` | `匹配 38 个`（规则作用于一整批） |
| `div[` | `选择器语法无效`，选择不变 |
| `.definitely-not-here` | `没有元素匹配这个选择器`，选择不变 |

## 2. 浮层面板不再卡出屏幕

面板高度会变（打开调色盘 / 混合器、出现语义色或范围行）。以前只在选中元素和 `scroll / resize` 时摆位置，
元素贴着视口底部时用「矮面板」算的位置，长高后就顶出屏幕 —— 实测 bottom 超出视口 136px，`应用 / 取消`
点不到。

现在：每次渲染后重新摆放（rAF 合并）、两轴都夹在视口内（8px 边距，放不下就翻到元素上方）、
`max-height = min(74vh, 视口高-16)`、`max-width = 视口宽-16`，打开取色器时自动滚进可视区。
320px 宽视口下实测面板 `[8, 8, 312, 452]`，完全在内。

顺带修掉旧问题：在行内输入框里按 `Esc` 原本会把整个面板关掉（窗口捕获监听先跑），现在只取消这次输入。

安装同 README；已装过的刷新页面（F5）即可，面板标题应显示 `v0.5.5`。
